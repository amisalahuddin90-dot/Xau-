# XAU SMC+ICT floating signal bubble (free)
Build without a PC tools: create a free GitHub repo, upload this folder, open Actions > "Build APK" > Run workflow,
then download `xau-signal-apk` and install app-debug.apk (allow "install unknown apps").
Or open the folder in Android Studio and press Run.
Open the app: 1) Allow overlay  2) Start bubble. Tap the bubble to expand; drag to move.
